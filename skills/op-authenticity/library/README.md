# OP Authenticity Library

Curated packs that give the profile real local and industry knowledge, so every OP product starts where the last one finished.

## How to use (Step 2 — Match)
1. Pick **one region pack**, **one language pack** (if the product is not English-only) and **one or two industry packs**.
2. Read only those packs.
3. Use them to: sharpen gap questions, fill rules (Always / Never), set formats and tokens, and add checks to the Design Brief.
4. Tell the user which packs you used. Mark pack-sourced facts in the profile as "(library: <pack>)".
5. Packs are starting points, not proof about this client. A pack fact supports a score of 2 only when it clearly applies to this product. Facts about laws, regulators and services change: verify with web search when you can, and always mention the pack's review date when you rely on a legal fact.

## Pack anatomy (every pack has the same six parts)
- **Signals** — what is usually true in this region/industry.
- **Do** — rules to apply by default.
- **Don't** — common mistakes that make a product feel foreign or wrong.
- **References** — services, apps, regulators and systems people already know.
- **Tokens** — formats and defaults (locale, direction, currency, week, phone).
- **Checks** — what the guard and QA should test.

## Adding a pack
Copy the anatomy above, add an owner and review date, and cite sources for every legal or market fact. The Library Curator reviews packs monthly and merges lessons from approved profiles.
